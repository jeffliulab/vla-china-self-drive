## 1. 心智模型①：控制层在栈里的位置

回顾第一课 [§1.1](1-自动驾驶模型.md) 的栈：`感知 → 预测 → 规划 → 控制`。本课做的是**最右边「控制」**，外加一点"规划"的退化版（沿 waypoint）。

```
高层动作(VLA/规则, 1–2Hz)  ──设目标──►  控制器(20Hz, 本课)  ──►  carla.VehicleControl(throttle,steer,brake)
   如 SLOW_DOWN / STOP                   纵向PID控速 + 横向跟 waypoint              物理引擎积分→车动
```

两条铁律（第一课已立，这里落地）：
- **高层只设目标，底层反馈闭环去够**，不是回放预算好的动作（第一课 [§5.3.1](1-自动驾驶模型.md) 的"反馈闭环≠回放"）。
- **底层不直接改速度**，它输出油门/刹车这种"力级"指令，速度是物理响应（第一课 [§4.2](1-自动驾驶模型.md)）。

> 本课的"规则 baseline"对应实验设计的**第一个 agent**（rule baseline，三方 ablation 之一），也是第四课采专家数据的 **expert**（第一课 [§5.6](1-自动驾驶模型.md)）——一鱼两吃。

## 2. 心智模型②：行人 = 弱势 actor 的两种控制方式

行人（`walker.pedestrian.*`）是 actor，但控制方式和车不同，且鬼探头全靠它。两种方式：

| 方式 | 怎么做 | 特点 | 用在哪 |
|---|---|---|---|
| **AI 控制器** | `controller.ai.walker` 子 actor：`start()` → `go_to_location()` → `set_max_speed()` | 自然行走、**会自动避让车辆** | 背景人群、自然交通 |
| **手动控制** | `walker.apply_control(WalkerControl(direction, speed))` | 直接命令方向+速度、**不避让、说窜就窜** | **鬼探头的精确横穿** |

> 关键：**鬼探头必须用手动 `WalkerControl`**。AI 控制器会"懂事地避让"，营造不出"突然窜出、来不及反应"的威胁（第一课 [§3](1-自动驾驶模型.md) 的难点本质）。行人是**运动学控制**（直接按方向+速度移动，不走完整刚体物理，第一课 [§4.2](1-自动驾驶模型.md) Q2），所以横穿速度你能精确设定。

## 3. 必须知道的原理

> 本课的"硬"部分：把"沿路开、平稳不画龙"讲成控制律。这些是经典控制，不是 DL。

### 3.1 车辆运动学：自行车模型（bicycle model）

把四轮车简化成"前后两个轮"的**运动学自行车模型**，状态 $(x,y,\theta,v)$、输入前轮转角 $\delta$ 与加速度 $a$：

$$
\dot x = v\cos\theta,\quad \dot y = v\sin\theta,\quad \dot\theta = \frac{v}{L}\tan\delta,\quad \dot v = a
$$

$L$ 是轴距。**为什么要知道它**：横向控制（转方向盘）和纵向控制（油门刹车）就是分别去操纵 $\delta$ 和 $a$；它告诉你"打多少方向盘→车头转多快"，是所有横向控制律的基础。

### 3.2 纵向控制：PID 控速

目标：让当前速度 $v$ 追上目标速度 $v_{\text{target}}$（目标由高层动作设——`SLOW_DOWN` 调低、`STOP` 设 0）。误差 $e=v_{\text{target}}-v$，PID 控制律：

$$
u(t)=K_p\,e + K_i\!\int e\,\mathrm dt + K_d\,\frac{\mathrm de}{\mathrm dt}
$$

- $u>0$ → 给油门（`throttle=clip(u,0,1)`，`brake=0`）；$u<0$ → 给刹车（`brake=clip(-u,0,1)`，`throttle=0`）。**油门和刹车不要同时给**。
- $K_p$ 反应快慢、$K_i$ 消稳态误差、$K_d$ 抑制超调/震荡。离散实现里 $\int$ 用累加、$\mathrm de/\mathrm dt$ 用差分（步长 = `fixed_delta_seconds`）。

### 3.3 横向控制：让车沿 waypoint 走

横向控制把车"吸"到车道中心线（一串 waypoint，第一课 Q1/Q15）。三种经典法：

| 方法 | 思路 | 一句话 |
|---|---|---|
| **PID（横向）** | 对"横向偏差 + 航向偏差"做 PID | 简单，CARLA `VehiclePIDController` 默认就是它 |
| **Pure Pursuit（纯追踪）** | 瞄准前方 $L_d$ 处的目标点，几何法算转角 | $\delta=\arctan\dfrac{2L\sin\alpha}{L_d}$，$\alpha$=车头到目标点的夹角 |
| **Stanley** | 同时管前轴的横向偏差 $e$ 和航向误差 $\psi$ | $\delta=\psi+\arctan\dfrac{k\,e}{v}$ |

**本项目**：直接用 CARLA 自带的 `VehiclePIDController`（横纵都 PID）即可，不用自己造（第一课 Q10）。理解上知道 Pure Pursuit/Stanley 是更"几何/鲁棒"的替代即可。

### 3.4 高层动作 → 控制器目标：映射表

这是把第一课 [§5.3.1](1-自动驾驶模型.md) 的映射落到本课控制器的**目标参数**：

| 高层动作 | 控制器目标 | 控制器怎么实现 |
|---|---|---|
| `KEEP_LANE` / 前进 | 目标速度=巡航速度，目标车道=当前 | PID 控速 + 跟当前车道 waypoint |
| `SLOW_DOWN` / 减速 | 目标速度↓ | PID 把速度拉低 |
| `STOP` | 目标速度=0 | PID 满刹 |
| `FOLLOW` | 目标速度=前车速、保持车距 | 自适应巡航（按车距调目标速度） |
| `YIELD` | 有冲突 actor→0，否则巡航 | 条件判断 + PID |
| `CHANGE_LEFT/RIGHT` | 目标车道=左/右邻车道 | `wp.get_left_lane()`/`get_right_lane()` 换 waypoint 序列 |
| `TURN_LEFT/RIGHT` | 路口选对应转向分支 | `wp.next()` 在路口的多分支里挑 |

> 规则 baseline 的"会刹"= 一条最简策略：正常按 `KEEP_LANE` 巡航；**前方一定距离内出现行人/障碍 → 切 `STOP`**（用深度/语义/actor 距离判断，第一课 [§2.5 / Q13](1-自动驾驶模型.md)）。这条"写死"逻辑正是第一课 [§3.1 / §5](1-自动驾驶模型.md) 说的：单场景有效、不泛化——所以才需要 VLA 去泛化。

## 4. 实践：CARLA Python client

### 4.1 API 速查（本课最小集）

| 目的 | 调用 |
|---|---|
| 发控制 | `vehicle.apply_control(carla.VehicleControl(throttle=.., steer=.., brake=..))`（throttle/brake∈[0,1]，steer∈[-1,1]） |
| 现成 agent | `from agents.navigation.basic_agent import BasicAgent`；`agent=BasicAgent(vehicle)`；`agent.set_destination(loc)`；`ctrl=agent.run_step()`；`agent.done()` |
| 现成 PID | `from agents.navigation.controller import VehiclePIDController`；`pid=VehiclePIDController(vehicle, args_lateral={'K_P':..,'K_I':..,'K_D':..,'dt':0.05}, args_longitudinal={...})`；`ctrl=pid.run_step(target_speed, waypoint)` |
| 全局路径 | `from agents.navigation.global_route_planner import GlobalRoutePlanner`；`grp=GlobalRoutePlanner(map, 2.0)`；`route=grp.trace_route(start, end)` |
| waypoint | `wp=map.get_waypoint(loc, project_to_road=True)`；`wp.next(d)`；`wp.get_left_lane()`；`wp.transform/lane_id/road_id` |
| spawn 行人 | `bp=random.choice(bp_lib.filter('walker.pedestrian.*'))`；`walker=world.try_spawn_actor(bp, tf)` |
| 行人 AI | `c_bp=bp_lib.find('controller.ai.walker')`；`ctrl=world.spawn_actor(c_bp, carla.Transform(), attach_to=walker)`；`ctrl.start()`；`ctrl.go_to_location(world.get_random_location_from_navigation())`；`ctrl.set_max_speed(1.4)` |
| 行人手动（窜出） | `walker.apply_control(carla.WalkerControl(direction=carla.Vector3D(x,y,z), speed=2.0, jump=False))` |
| 行人可复现 | `world.set_pedestrians_seed(seed)` |

### 4.2 「窜出」函数骨架（为第四课触发做准备，写代码前征得同意）

```
def make_dart(walker, cross_dir, speed):       # cross_dir: 垂直马路指向对面的单位向量
    walker.apply_control(carla.WalkerControl(
        direction=cross_dir, speed=speed, jump=False))
# 平时让行人藏在遮挡物后不动/慢走；
# 主循环里检测 ego 到行人的距离 < 触发阈值 D 时，调 make_dart(...) → 行人瞬间直线冲出
```

### 4.3 规则 baseline 骨架

```
用 BasicAgent/PIDController 让 ego 沿路线巡航(目标速度 v0)
每个 tick:
    if 前方 D 米内有行人/障碍(用深度或可见 actor 判断):
        高层动作 = STOP → 控制器目标速度=0(满刹)
    else:
        高层动作 = KEEP_LANE → 巡航
    vehicle.apply_control(控制器.run_step(...))
```

### 4.4 常见坑

- **PID 调不好** → 画龙/震荡/刹不住：先调 $K_p$ 再加 $K_d$，$K_i$ 小心积分饱和。
- **steer 方向搞反** → CARLA 左手系 yaw 俯视顺时针为正（第一课 [§4.1](1-自动驾驶模型.md)），横向控制符号容易反，车往反方向拐。
- **throttle 与 brake 同时给** → 行为诡异；二选一。
- **spawn 行人没配 controller** → 行人站着不动（AI 方式必须 spawn `controller.ai.walker` 并 `start()`）。
- **想要"窜出"却用 AI 控制器** → 行人会避让，造不出威胁；用手动 `WalkerControl`。
- **行人 spawn 在非可行走区** → spawn 失败/卡住；用 `get_random_location_from_navigation()` 取导航网格上的点。
- **没设 `set_pedestrians_seed`** → 行人导航不可复现（与第二课同步一起，才完整可复现）。
