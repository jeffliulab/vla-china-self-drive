# 中国路况：研究目标梳理

本文件梳理本项目要探讨的**中国式混合交通研究目标**——即「研究什么现象」。
属于规划/讨论性质，与 [PROJECT_PLAN.md](PROJECT_PLAN.md) 同级（想做什么），区别于 [CLAUDE.md](../CLAUDE.md)（现在是什么）。
场景细化（触发条件、对手行为参数、成败判据）后续对接 PLAN 第 2 阶段。

---

## 0. 统一内核

> **中国式混合交通的本质 = 高密度弱势交通参与者（尤其电动车）+ 规则弱约束 + 意图高度不确定 + 靠「博弈/试探」而非「让行规则」来协调。**

标准自动驾驶的假设——大家守规则、各行其道、有路权就能走——在这里**全部失效**。这是本项目的科学切入点。

研究目标拆成**三个维度**（场景 / 对手行为 / 考察能力是三件不同的事，不要混）：

- **维度 A — 典型场景**：把车放进什么处境。
- **维度 B — 对手行为模型**：其他 actor 怎么「不守规则」。← 真正的难点
- **维度 C — 考察能力 / 研究问题**：到底要回答什么科学问题。← 目标的本体，也是评测表的列

---

## 维度 A：典型场景（staged situations）

按危险来源分四类。

### A1. 遮挡 + 突现（鬼探头类）
- 公交车 / 大货 / 路边停车后窜出的行人、电动车。
- 难点：目标出现前 **TTC 极短**，必须「**还没看见就先减速**」（基于遮挡的预防性慢行）。
- 考察：遮挡风险感知、主动降速。

### A2. 二轮车不规则交互（电动车签名场景）★ 最具中国辨识度
- 加塞 / 穿插、无征兆变道、**逆行**、贴车流缝里钻、盲区冒出。
- 右转时与**直行非机动车**冲突（中国右转事故经典款）。
- 难点：二轮车**不待在车道里、不守信号、意图不稳**。
- 考察：对弱势参与者的意图推断 + 保护性决策。

### A3. 路口博弈（无明确让行）★ 最有研究价值、最被忽视
- 非保护左转 vs 对向车：对面**刹一下又加速、不一定让，是在看时机**。
- 无信号 / 弱信号路口的多方互相试探。
- 窄路会车「谁先过 / 谁后退」。
- 难点：**对方不保证让行**，是动态博弈，不是「检测到障碍 → 停」。
- 考察：**博弈式时机决策——既不能太怂（僵在原地不敢动，"freezing robot"），也不能太莽（抢 → 碰撞）**。

### A4. 车辆侵略性行为
- 加塞 / 强行并线、匝道汇入抢位、前车急刹、占道停车 / 双排停车逼你借对向道绕行。

## 维度 B：对手行为模型（adversary behavior）← 项目成败的关键层

**最容易被低估、但决定数据集质量的一层。** CARLA 自带 TrafficManager 太「守法」——不会闯红灯、逆行、加塞、玩让行博弈。所以「中国式」**不在场景布置，而在给其他 actor 写行为控制器**。

| 对手行为 | 默认 TM 能做吗 | 需要补什么 |
|---|---|---|
| 守规则跟车 / 变道 | ✓ | — |
| 鬼探头（定时从遮挡后窜出） | ✗ | 触发式脚本 |
| 电动车逆行 / 穿插 | ✗ | 自定义二轮车控制器 |
| 路口博弈（刹了又加速、看时机让 / 不让） | ✗ | **博弈行为模型**（最难也最值钱） |
| 行人闯红灯 / 群体横穿 | ✗ | 自定义行人触发 |

> **建议把「对手行为库」当成和「ego agent」同等重要的研究模块。** 中国式数据集的真实度，直接取决于这些对手「坏」得有多真实。这本身可能是一个独立贡献点。

---

## 维度 C：考察能力 / 研究问题（目标的本体）

场景是壳，真正要回答的科学问题——也是最终评测表的列：

1. **意图推断**：意图模糊时（电动车会不会窜？对面车会不会让？）预测得准不准？
2. **遮挡预防性决策**：看不见威胁时会不会提前减速？
3. **博弈式时机决策**：assertiveness 能不能校准？（怂 ↔ 莽 之间）
4. **对规则违反者的鲁棒性**：别人不守规则时，ego 还安全吗？（不假设别人守规则）
5. **弱势者优先**：即便 ego 有路权，会不会保护行人 / 二轮车？
6. **多目标同时交互**：同时应付多个威胁，而非一次一个。
7. **中文指令遵循 + grounding**：语言条件到底有没有用？（VLA 的核心卖点）

## 优先级排序（研究价值 × 中国特色 × 可行性）

| 优先级 | 目标 | 理由 |
|---|---|---|
| **第一梯队** | **A3 路口博弈** + C3 博弈时机决策 | 最 novel、最被现有 benchmark（Bench2Drive 多是「检测 → 让」）忽视；「对方不一定让」是真问题 |
| **第一梯队** | **A2 电动车交互** + C5 弱势者优先 | 最具中国辨识度，是数据集的灵魂 |
| 第二梯队 | A1 鬼探头 + C2 遮挡预防 | 经典且重要，但 benchmark 里较常见，novelty 一般 |
| 第二梯队 | C7 语言指令有没有用 | VLA 立项卖点，必须验证，但依附在上面场景里做 |
| 第三梯队 | A4 加塞 / 急刹 | Bench2Drive 等已有，做对照可以，别当主菜 |

**核心建议**：别贪多。先锁定 **「路口博弈」+「电动车交互」** 两个第一梯队目标，把对手行为模型做扎实，这两个足以撑起一个有特色、有贡献的研究框架。鬼探头、加塞作为场景库扩展和对照组即可。
